Flow:

Client
  │
  │ Authorization: Bearer <accessToken>
  ▼
auth.middleware.js
  │
  ├── Check token
  ├── Verify JWT
  └── Extract userId
        │
        ▼
     Controller
        │
        ▼
    PostgreSQL


GET /me
    ↓
authenticate
    ↓
getMeController

The controller cannot run unless authentication succeeds.

                    LOGIN
