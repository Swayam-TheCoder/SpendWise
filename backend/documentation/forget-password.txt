Overall flow:
Forgot Password
      ↓
Enter email
      ↓
Generate random reset token
      ↓
Hash token
      ↓
Store hash in DB
      ↓
Send email
      ↓
User clicks reset link
      ↓
New password
      ↓
Verify token
      ↓
Hash new password
      ↓
Update password
      ↓
Invalidate existing sessions
